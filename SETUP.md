2. If GitHub offers the profile README option, enable it. An empty README is fine because this package contains the final one.
3. Upload `README.md`, the `assets` folder, and `.github/workflows/snake.yml`.
4. Commit the files.
5. Open `https://github.com/sudipta629` and refresh.
6. The Snake workflow may take a little time to create its output branch; GitHub Actions can also be run manually from the Actions tab.

Important: do not create a different repository name for the profile README. It must match the username: `sudipta629`.

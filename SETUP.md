# SUDIPTA629 — GitHub Profile Setup

## 1. Create the profile repository

Create a **Public** repository with exactly this name:

`sudipta629`

The repository name must match the GitHub username for GitHub to show its README at the top of the profile.

## 2. Upload everything

Upload the complete contents of this folder, preserving the structure:

```text
sudipta629/
├── README.md
├── assets/
│   ├── profile.jpg
│   ├── hero.svg
│   └── footer.svg
└── .github/
    └── workflows/
        └── snake.yml
```

## 3. Commit

Commit to the repository's default branch.

## 4. Check the profile

Open:

https://github.com/sudipta629

## 5. Snake

The GitHub Action runs automatically once per day and can also be started manually:

Repository → Actions → Generate Contribution Snake → Run workflow

The first run may take a little time before the snake file appears.

## 6. Important

The README intentionally uses GitHub-supported Markdown/HTML and external image widgets instead of JavaScript/CSS. GitHub does not provide a normal webpage runtime inside a profile README, and SVG scripting/animation should not be relied upon.

If an external stats service is temporarily unavailable, the rest of the profile still renders.

## 7. Optional profile settings

For the complete profile experience, also set in GitHub:

- Profile photo
- Bio
- Location
- Social links
- Pinned repositories (up to 6)
- Profile status

Keep the profile repository Public.
